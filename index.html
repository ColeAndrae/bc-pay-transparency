The problem

~8,500 first-time filers

From November 1, 2026, every provincially regulated B.C. employer with 50 or more employees must post a pay transparency report. In 2025 the rule applied to about 700 employers.

Your payroll system doesn't export it

The province's tool needs a 7-column CSV. A payroll register has dozens of pay codes: regular, stat, vacation, 4% vacation pay, OT 1.5, shift premium, car allowance, retro, severance…

The rules are easy to get wrong

Vacation taken counts as ordinary pay, but vacation paid out is excluded. Stat pay is never overtime. Overtime hours don't count as hours worked. Special Salary is only for lump sums with no set hours.

Every rejected row means another trip to Excel

The province's tool rejects a file row by row, for example when a row has hours but no ordinary pay, or overtime pay without overtime hours. This page runs the same checks as you map, and tells you how to fix each one.

Privacy

  • Nothing is uploaded. The page reads your file with your browser's own file reader. The page's Content-Security-Policy blocks all network requests (connect-src 'none'), so it couldn't send your data anywhere even if it tried.
  • You can check this. Open your browser's developer tools, go to the Network tab, and load a file: no requests appear. Or save this page and use it offline.
  • The output has no names or IDs. It has only the seven columns the province asks for. The only thing kept in your browser is how you mapped your pay codes, such as "REG → Ordinary"; no pay figures are stored.
